## Описание проекта

Этот проект представляет собой фронтенд-клон интерфейса Google Gemini. Он демонстрирует навыки верстки сложных пользовательских интерфейсов, адаптивного дизайна и работы с утилитарными CSS-фреймворками. Проект является полностью статическим и не включает серверную часть или реальную интеграцию с языковыми моделями.

---

## Стек технологий

- **HTML5** — семантическая разметка страницы
- **Tailwind CSS** — утилитарный фреймворк для быстрой и гибкой стилизации интерфейса
- **JavaScript** (минимально) — базовая интерактивность элементов интерфейса и обработка отключенного JS (noscript)

---

## Запуск локально

Проект является полностью статическим и не требует установки зависимостей (Node.js, npm и т.д.).

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Kievsky332/Gemini-tailwind.git
   ```
2. Перейдите в папку
   ```bash
    cd Gemini-tailwind
   ```
3. Откройте файл index.html двойным кликом в любом современном браузере.
